# FitProcessFlow — Day 1 smoke (no Maestro required)

1. `npm start` then open iOS simulator or Expo Go.
2. Create account (any 8+ char password). Without Firebase keys this stays on-device.
3. Home shows 0/4 week chips.
4. Train → start Full body A.
5. Complete 1 set (weight + reps). Rest timer starts. Skip rest.
6. End session. History shows the log.
7. Kill the app, reopen, still signed in (local persist).
