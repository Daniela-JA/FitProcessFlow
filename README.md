# FitProcessFlow

Quiet-luxury training + kitchen log. Dark only. Deadpan on Train/Food. Cheerleader on Insights.

## Run

```bash
npm start
npm test
```

## First-run
1. Create an account (8+ character password). Firebase optional — `.env.example`.
2. Settings: sex (required), Minimalist vs Max Results, 2–6 days/week.
3. Train → Tape. Then Home scores unlock from LBM.
4. Food is already full (~80 PT supermarket recipes).

Photos never upload. Tape is the BF% source of truth.

See `VERSION.md` and `scripts/smoke.md`.
